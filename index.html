TNG Monthly Agent is an independent, personal utility that downloads an official Touch 'n Go card transaction statement and creates separate toll and parking PDFs on the user's Windows computer.

This website contains information only. It does not sign users in, access Gmail, accept file uploads, or process statements. Google authorization takes place in the local Windows application.

What the application does

  1. Signs in to the official TNG Card Portal through normal browser interactions, using credentials protected on the user's computer.
  2. When the portal requests email verification, reads recent messages through an authorized Gmail connection to identify the newly requested TNG one-time password, then fills it locally.
  3. Downloads the requested month's official PDF statement and verifies the statement period and selected card.
  4. Creates separate PDFs retaining complete transactions for the specified toll or parking merchant, including transactions that continue onto another page.

Why Gmail access is requested

The application requests gmail.readonly to find the email verification code needed for a TNG login. Google does not offer a Gmail OAuth scope limited to messages from one sender. The application filters recent messages locally by request time, pre-existing message IDs, sender rules, and TNG verification content. It does not request permission to send, modify, or delete email.

Where your data stays

TNG credentials and Google authorization tokens are encrypted for the current Windows user with Windows DPAPI. Statements, filtered PDFs, and non-sensitive verification records stay in local folders. Email contents and verification codes are not sent to an AI model, displayed in logs, or uploaded to this website.

Read the privacy policy for data handling, retention, and revocation details.

Personal, independent software

This utility is intended for its owner's personal use. It is not operated, sponsored, or endorsed by Touch 'n Go or Google. It does not bypass CAPTCHA, MFA, or the portal's security controls. Monthly scheduling depends on a working computer, internet access, valid authorization, and the availability of the external services.

Contact the owner through GitHub Issues. Do not post account details, statements, credentials, or verification codes in a public issue.
