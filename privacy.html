Privacy policy

This policy describes the personal Windows application TNG Monthly Agent and this informational website, maintained by GitHub user punmin1125.

Google data accessed and purpose

The Windows application uses Google's official OAuth authorization and Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly. It retrieves recent message identifiers, headers, timestamps, and, when checking candidates, message bodies. These are used only to identify and extract the TNG email verification code produced by the current login request.

The application may temporarily read recent messages that are not TNG verification messages while identifying candidates. Non-matching messages are discarded from the application's working memory and are not saved. The application does not send, edit, archive, label, or delete Gmail messages.

Local storage and protection

TNG login credentials and Google access and refresh tokens are stored locally in encrypted form using Windows DPAPI for the Windows user running the application. The application decrypts them in process memory when needed.

Original statements, filtered PDFs, backups from explicit reruns, and verification records are saved in local folders. The original statements and their account summaries may contain personal information. PDF files are not themselves encrypted by this application; the Windows user controls their access, storage, backups, and deletion.

Email bodies and OTP values are processed in memory. They are not intentionally stored in application logs, notifications, generated PDFs, or persistent email archives. Logs and notifications are limited to operational steps, statement months, page counts, target transaction counts and totals, validation results, and sanitized errors.

Sharing and external services

The local application communicates with Google to authorize Gmail access and retrieve candidate messages, and with the official TNG Card Portal to sign in and obtain statements. The application does not send email content, OTP values, credentials, or statement files to an AI model or this website. It does not sell Google user data, use it for advertising, or use it to train AI models.

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Authorization tokens remain encrypted on the computer until the user replaces or deletes them. Statement files and backups remain in local folders until the user deletes them. Removing local tokens does not by itself revoke Google's authorization grant.

You can revoke Google access through your Google Account connections settings. You can also delete the local token and credential files and downloaded statements. After access is revoked, automatic Gmail OTP retrieval will stop until authorization is granted again.

This website

This is a static informational website hosted by GitHub Pages. It contains no analytics scripts, application login, upload form, or Gmail connection. It does not intentionally set tracking cookies. GitHub may process ordinary connection information needed to serve the site under the GitHub Privacy Statement.

Contact and policy changes

For questions, open a GitHub issue for the site owner. Public issues must not contain personal account information, statements, passwords, tokens, or verification codes. Policy changes will be published on this page with an updated effective date.
